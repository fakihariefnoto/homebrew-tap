# homebrew-tap

Fakih Arief Noto's Homebrew tap.

## Formulae

| Formula | Description |
|---|---|
| [commitly](https://github.com/fakihariefnoto/commitly) | Compose Conventional Commits messages, interactively |
| [ocsa](https://github.com/fakihariefnoto/ocsa) | Report on and reclaim the disk OpenCode's SQLite store uses |

## Install

```sh
brew tap fakihariefnoto/tap
brew install fakihariefnoto/tap/commitly
brew install fakihariefnoto/tap/ocsa
```
